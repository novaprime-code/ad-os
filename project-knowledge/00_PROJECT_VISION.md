# LifeOS — Personal Operating System

## Purpose

Build a zero-cost Personal Operating System for a Master's student with ADHD/AuDHD tendencies.

The system acts as:
- **Memory** — captures every idea, note, task before it's forgotten
- **Planner** — generates daily plans based on goals, energy, and calendar
- **Scheduler** — syncs tasks to Google Calendar automatically
- **Accountability System** — morning briefs, night reviews, weekly reviews
- **Knowledge Base** — searchable personal knowledge layer

## User Profile

- Master's student (Computational Modeling & Simulation, TU Dresden)
- Full-stack developer (React, Laravel, Python, 3+ years experience)
- ADHD/AuDHD — forgets ideas, struggles with routine, likes rules but fights executive dysfunction
- Budget: €0/month for tools
- Heavy Google ecosystem user
- Needs the system to run 24/7 without maintenance

## Design Principles

1. **Capture > Organization** — Getting it in is more important than filing it perfectly
2. **Execution > Planning** — Don't spend 2 hours planning a 1-hour task
3. **Consistency > Perfection** — A mediocre system used daily beats a perfect system abandoned
4. **One tap, one command** — If it takes more than one step, it won't get done
5. **AI fills the gaps** — Gemini handles categorization, prioritization, summarization
6. **No frontend for 6 months** — Telegram is the only UI. No React. No dashboards. Use it first.
7. **Settings page only** — The ONE web page allowed is the configuration/settings page served by Apps Script

## Non-Goals (For Now)

- No web dashboard
- No mobile app
- No database beyond Google Sheets
- No hosting/servers
- No Docker, Redis, Postgres
- No over-engineering
